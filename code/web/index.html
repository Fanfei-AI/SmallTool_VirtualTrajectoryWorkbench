连接与准备

首次安装：先下载依赖

仅下载本软件代码还不能运行，请先联网完成以下安装；已配置好的电脑无需重复安装

  1. Python 3.13：安装 Python 运行环境，并包含 pip 包管理工具
  2. pymobiledevice3 11.34.1 及其依赖：安装到项目使用的独立 Python 环境，用于通过 USB 连接手机并写入模拟坐标
  3. Apple USB 驱动与服务：安装 Apple Devices 或 iTunes 所提供的设备支持组件，确保电脑能识别手机；无需安装图形化虚拟定位软件

首次建立开发者连接时，还可能需要联网下载开发者支持文件。地图组件和在线底图也需要网络加载

开启开发者模式

在手机“设置 → 隐私与安全 → 开发者模式”中开启开发者模式，按提示重启，再确认开启并输入手机密码

连接手机

  1. 使用支持数据传输的数据线连接手机与电脑，并解锁手机
  2. 如出现提示，在手机上选择“信任”，并按要求输入手机密码；电脑端如有信任提示，也请确认
  3. 只连接一台需要操作的手机，运行期间保持 USB 连接，避免电脑休眠

如果找不到开发者模式选项，或电脑无法识别手机，请先完成设备配对及驱动准备，再尝试启动轨迹
